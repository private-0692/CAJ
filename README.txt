CAJ Corporation Construction — versión editable

index.html: página pública.
admin.html: editor de nombre, correo, teléfono, textos, servicios y fotos.

IMPORTANTE:
Esta versión es una web estática. El editor guarda cambios en localStorage del navegador, por lo que NO publica cambios automáticamente para todos los visitantes.
Para un panel real multi-dispositivo se necesita un backend/CMS con autenticación y base de datos. No uses contraseñas o tokens dentro de HTML/JavaScript.
