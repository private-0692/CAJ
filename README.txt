PROYECTO WEB PROFESIONAL

Archivos separados:
1. index.html  = página pública
2. styles.css  = diseño de la página
3. app.js      = contenido dinámico
4. admin.html  = panel de administración
5. admin.css   = diseño del panel
6. admin.js    = edición y guardado

USO:
- Abre admin.html para editar textos, teléfono, email y fotos.
- Pulsa "Guardar cambios".
- Pulsa "Vista previa" para abrir la página.
- Las fotos se pueden cambiar pegando sus URLs.

IMPORTANTE:
Esta versión usa localStorage del navegador. Para que los cambios sean visibles para TODOS los visitantes de una página publicada, hay que conectar el Admin Panel a una base de datos/backend (por ejemplo Firebase, Supabase o un servidor propio).
